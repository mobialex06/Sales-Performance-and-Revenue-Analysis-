# 📊 Sales Performance and Revenue Analysis

## 📌 Project Overview

Sales Performance and Revenue Analysis is an interactive Power BI dashboard project developed to analyze sales and revenue data from different business perspectives.

The dashboard provides a comprehensive view of sales performance by analyzing revenue, sales amount, orders, quantity, products, sales channels, regions, payment methods, and order status.

The main goal of this project is to transform raw sales data into meaningful visual insights that can help businesses understand their performance and identify important trends.

---

## 🎯 Objectives

- Analyze overall sales and revenue performance
- Track total sales, revenue, orders, and quantity
- Compare sales performance across different sales channels
- Analyze revenue by region
- Understand customer payment preferences
- Identify product-wise sales performance
- Analyze order status such as Completed, Cancelled, Returned, and Pending
- Create an interactive and user-friendly Power BI dashboard
- Support data-driven business analysis

## ⚙️ Data Analysis Process

The project follows these major steps:

1. **Data Collection**
   - Imported sales data into Power BI.

2. **Data Cleaning**
   - Cleaned and transformed the dataset using Power Query.
   - Checked data types and prepared fields for analysis.

3. **Data Modeling**
   - Organized the data for effective reporting.
   - Created required calculated measures using DAX.

4. **Dashboard Development**
   - Created KPI cards.
   - Added bar charts, line charts, donut charts, tables, and gauges.
   - Added interactive navigation and dashboard pages.

5. **Data Analysis**
   - Analyzed sales, revenue, products, regions, channels, payment methods, and order status.

6. **Insight Generation**
   - Identified important sales patterns and performance trends.
